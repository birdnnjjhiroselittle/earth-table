# 行動の橋：狩りと実り

[English](action-bridge.en.md) | **日本語**

**太古の楽しさで、現代の無駄を救う。遊んだ分だけ、自分も町も健康になる。**

## 1. なぜ楽しいのか

太古の時代、体の強い者は獲物を狩り、それ以外の者は木の実などを採集しました。「探す・獲る・作る・分ける」ことは生き残りに直結していたので、脳はそれを **楽しい** と感じるようにできています。今でも釣り・山菜採り・道具づくり・料理を趣味として楽しめるのはそのためです。

農耕と工業化で飽食の時代になり、その楽しみは趣味やゲームへ移りました。
「狩りと実り」は、その楽しみを **もう一度、本物の食べものとつなぎ直します。**

## 2. 遊びと現実の対応

| 太古の本能 | ゲームでの遊び | 現実で起きていること | 報酬 |
|---|---|---|---|
| **採集** | 地図に「実り」が出現。歩いて集める | 閉店前に余りそうなお弁当・期限の近い食品を救う | その食品、割引 |
| **狩り** | 珍しい獲物、時間限定のイベント | 獣害で駆除された鹿・猪（ジビエ）、市場に出ない魚（未利用魚）を活かす | 肉・魚 |
| **大物狩り** | 30人で挑む「収穫レイド」 | 人手不足の農家の収穫を手伝う | 規格外の野菜、収穫物の一部 |
| **道具づくり** | 素材を組み合わせるクラフト | 家の冷蔵庫の余り物で料理する「使い切りクエスト」 | レベルアップ、ポイント |
| **育てる** | 畑を育てる | 家庭菜園・市民農園 | 収穫物 |
| **分ける** | 仲間に届ける「おすそ分けクエスト」 | 子ども食堂・食べものに困っている人へ届ける | 地域ポイント、町の感謝 |
| **知恵を伝える** | 図鑑を埋める、見分けの達人 | 野菜の写真で、鮮度判定AIの学習を手伝う | 称号、ポイント |

## 3. なぜ本物の食べものがもらえるのか

食品ロスは「お金と手間をかけて作ったのに、誰の得にもならなかった価値」です。救えば、その価値を分け合えます。

| 払う人 | 得すること | プレイヤーへの報酬 |
|---|---|---|
| お店 | 捨てる費用が減る、売れ残りが売上になる | 救った食品、割引 |
| 農家 | 収穫の人手が確保できる | 規格外の野菜 |
| 自治体 | ごみ処理費が減る | 地域ポイント（減った処理費の一部から） |
| 健康保険組合・企業 | 病気が減り、医療費が下がる | 運動・野菜の摂取に応じたポイント |
| 獣害に悩む地域 | 畑の被害が減る | ジビエ肉 |

### 報酬＝影の価格

EARTH TABLE の地球ツインで「この町はトマトが余っている」となると、トマトを救うクエストの報酬が上がります。
**町で余っている物ほど報酬が大きい。** ゲームの報酬そのものが、地球全体の最適化の信号です。

## 4. 健康になるしくみ

- **歩いて集める**：実り・獲物は少し離れた場所に出るので、自然に歩く
- **キャラクターの体力＝自分の食事**：野菜を食べると回復、塩分が多いと少し重くなる。体型や体重を責める表現はしない
- **料理でレベルアップ**：自炊するほど腕が上がり、作れる料理が増える
- **季節イベント＝旬**：春の山菜、秋の実りなど、旬の物を食べると特別な報酬

## 5. 苦しむ人をなくすしくみ

- **困っている人も「プレイヤー」として参加できる**：施しではなく、遊んで食べものを手に入れる。自尊心を守る
- **動けない人向けのクエスト**：家でできる遊び（写真の仕分け、レシピづくり、電話での見守り）。高齢者や障害のある人も参加できる
- **届けることが見守りになる**：一人暮らしの高齢者へのおすそ分けが、安否確認にもなる
- **ギルド（町の仲間）**：競争より協力。町全体の目標（今月のロスを○kg減らす）をみんなで達成する

## 6. 守ること

| 危険 | 対策 |
|---|---|
| お店が「救ってもらえるから」と仕入れを増やす | 余りが増えたお店ほど報酬を下げる。予測で余りを減らすことを最優先にする |
| ゲーム依存・課金の誘導 | ガチャや有料課金はなし。1日の上限、休むことの推奨 |
| 歩きながらの操作による事故 | 移動中は画面に表示しない。ARグラスは安全な場所でだけ表示 |
| 食品の衛生 | 受け渡しは衛生のルールとガイドラインに従う。温度管理が必要な物は条件つき |
| 安い労働力扱い・仕事を奪う | 農家の手伝いは体験として扱う（法律の確認が必要）。既存の仕事を奪わない範囲にとどめる |
| 法律 | 景品表示法・賭博にあたらないか、労働法・食品衛生法を確認する |

## 7. 前例

- **ポケモンGO**：ゲームが、世界中の人を外へ歩かせた
- **Coke ON ウォーク**：歩数目標の達成でスタンプがたまり、ドリンクと交換できる
- **フードレスキューのアプリ**：余りそうな食品を、お店と買う人で結ぶ

「狩りと実り」は、これらを **食べもののロス・健康・困っている人の支援** の3つに同時につなげます。

## 8. 進め方

1. スーパー1店・農家数軒・子ども食堂1か所で、スマホの地図ゲームとして実験する
2. 家の冷蔵庫と連携し、使い切りクエストと料理を加える
3. 農家・猟友会と組み、収穫レイドとジビエを加える
4. ARグラス・イヤホンに対応する（「近くに実りがあります」）
5. EARTH TABLE の地球ツインとつなぎ、ツインの信号でクエストが出るようにする
