# ゲーム設計と現実への橋

[English](design.en.md) | **日本語**

## 1. 地球ツイン：何を再現するか

| 層 | 再現するもの | もとになるデータ（例） |
|---|---|---|
| 自然 | 気候・天気、土、水、作物の育ち方、漁場 | 気象データ、衛星画像、作物モデル |
| 生産 | 農地・牧場・漁業・加工工場、作付けと収穫 | FAOの統計、各国の農業統計 |
| 物流 | 港・航路・道路・倉庫・冷蔵の連鎖（コールドチェーン） | 港湾・物流の公開データ |
| 市場 | 値段、輸出入、在庫 | 国際価格、貿易統計 |
| 人 | 人口、年齢、所得、食習慣、栄養状態、病気 | 人口統計、栄養・健康調査 |
| 環境 | 温室効果ガス、水の使用、土地の変化、生物多様性 | 排出量の統計、衛星データ |

- 最初は、粗い地図と簡単なモデルから始め、データとプレイヤーが増えるほど細かくします。
- **個人のデータは入れません。** 入れるのは公開統計と、誰の分か分からない合計の数字だけです。

## 2. プレイの形

### 役割で遊ぶ
| 役割 | 決めること | 悩み |
|---|---|---|
| 農家 | 何を・どれだけ・いつ作るか | 天候、値段の変動、人手不足 |
| 漁師 | どこで・何を獲るか | 資源の枯渇、燃料費 |
| 物流会社 | どこへ・どう運ぶか、冷やすか | CO2、時間、傷み |
| お店・料理人 | 何を仕入れ・どう売るか | 売れ残り、客の予測 |
| 町長・国の代表 | ルール、補助、備蓄、貿易 | 選挙、予算、隣国との関係 |
| 医師・栄養士 | 町の人の健康を守る | 生活習慣病、栄養不足 |
| 家族 | 何を買い・作り・食べるか | 家計、時間、好み、健康 |

### 遊び方の種類
- **ストーリー**：「1億人が飢える干ばつの年を、誰も飢えさせずに乗り切れ」などのシナリオ
- **サンドボックス**：自由に国や町を作り、仕組みを試す
- **協力イベント**：世界中のプレイヤーが同時に、一つの危機（港の封鎖、パンデミック）に挑む
- **教育**：学校の授業で、食べものと地球のつながりを体験する

## 3. スコア：地球全体の目標

```
地球のスコア ＝ 健康寿命 ＋ 満足 − 飢える人 − 廃棄量 − CO2 − 水と土地の負荷
条件：どの国・地域・役割も、ゲーム開始時より悪くならない（パレート改善）
```

- 一つの国だけ豊かになっても、地球のスコアは上がりません。
- 誰かを犠牲にする手（ある国の農家をつぶす、など）は、条件違反で無効になります。
- 個人の成績（国・役割の成績）と、地球全体の成績の **両方** が見えるようにします。

## 4. 発見のしくみ：人の知恵 × AI

| | 人のプレイヤー | AI |
|---|---|---|
| 得意なこと | 思いがけない発想、価値の判断、文化の理解、交渉 | 大量の試行、細かい計算、何百年分の早送り |
| やり方 | 何百万人が、それぞれの立場で遊ぶ | 人の戦略を学び、自己対戦で磨く（AlphaGo型） |
| 出てくるもの | 新しい仕組み・ルール・協力の形 | その仕組みの最適な細かい設定、危険の予測 |

人が見つけた「意外な手」をAIが検証・改良し、AIが見つけた手を人が「本当に受け入れられるか」判断する、という往復をくり返します。

## 5. 現実への4つの橋

### ① 知恵の橋
- よい戦略は、**オープンな提案書** として公開します（どの条件で、どんな効果が、どんな危険があるか）。
- 誰でも検証できるよう、再現できるシナリオとデータをつけます。

### ② 実証の橋
- 提案は、いきなり国や世界では使いません。まず **1つの町・1つの農村** で小さく試します。
- 地域の人の同意を得て、効果と、損をした人がいないかを測ります。

### ③ データの橋
- 実証の結果をツインへ戻し、モデルのずれ（ゲームと現実の差）を直します。
- これをくり返すと、ツインの予測はより現実に近づきます。

### ④ 行動の橋
- ツインの信号（どこで何が余り・足りないか）が、現実のプレイヤーへのクエストになります。
- くわしくは [行動の橋：狩りと実り](action-bridge.md)。

## 6. 運営とお金

| 収入 | 内容 |
|---|---|
| 基本無料 | だれでも遊べる。課金で強くなる仕組みは入れない |
| 研究・行政の利用 | 研究機関・自治体・国際機関がシナリオ分析に使う |
| 企業の利用 | 物流・食品会社が、計画の検証に使う（データは合計のみ） |
| 寄付・基金 | 食べもののロスが減って浮いたお金の一部 |
| 教育 | 学校向けの教材 |

- 運営は、プレイヤー・研究者・生産者・自治体が持ち主になる **国際的な協同組合** のような形を目指します。
- ルールとモデルはオープンソースで公開します。

## 7. 危険と対策

| 危険 | 対策 |
|---|---|
| ゲームと現実の差（モデルの誤り） | 必ず小さな実証を挟む。予測の不確かさを表示する |
| ゲームが現実の政治の道具になる | ルール・データを公開し、誰でも検証できる。特定の国・会社が支配しない |
| 一部の人の意見だけが強くなる | 地域・年齢・所得のちがう人が参加できるよう、多言語・低スペック端末に対応 |
| 依存・課金 | ガチャなし、遊びすぎない設計 |
| データの悪用 | 個人のデータは入れない。国のデータは持ち主が管理 |
| 弱い立場の人の切り捨て | パレート改善を条件にする。損をする人がいる手は無効 |
