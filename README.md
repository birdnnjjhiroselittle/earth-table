# EARTH TABLE（地球の食卓）

[English](README.en.md) | **日本語**

**地球をもう一つ作って、そこで失敗しよう。現実では、もう誰も飢えさせないために。**

オープンワールドゲームの中に、地球の食べもの・健康・物流・環境の仕組みをまるごと再現します。世界中の人とAIがそこで遊んで解決策を見つけ、それを現実の世界に持ち込む構想です。

> 状態：構想段階（2026-11）。コードはまだありません。アイデア・意見・協力者を募集しています。

---

## 🌍 世界の矛盾

> 世界の食べものは、全員が食べられるだけ作られている。それなのに——
>
> - **6.7億人が飢えている**（2024年、世界人口の約8%）
> - **10億人以上が肥満**とともに暮らしている
> - **10.5億トンの食べものが捨てられている**（2022年、消費者が手にできる食べものの約19%。その60%は家庭から）
> - 捨てられる食べもの（食品ロス・廃棄）だけで、世界の温室効果ガスの **8〜10%** を出している

**足りないのは食べものではなく、つなぎ方。**
食べもの・健康・物流・環境は、別々の役所や会社、別々の国が、別々の目標で動かしています。全体を見て、全員が得をする手を探す場所がありません。

EARTH TABLE は、その場所を **ゲームとして** 作ります。

## 🧭 3つの世界をつなぐ

```
 ① 地球ツイン（オープンワールド）
    実際の気候・土・作物・港・航路・人口・栄養・値段・CO2を
    公開データと衛星で再現した「もう一つの地球」
          │  世界中のプレイヤーとAIが遊ぶ
          ▼
 ② 発見（人の知恵 × AI）
    何百万人の戦略 ＋ AIの自己対戦（AlphaGo型）
    → 作付け・物流・政策・献立の「よい手」が見つかる
          │  安全な順に現実へ
          ▼
 ③ 現実（実証の町 → 国 → 世界）
    よい手を実際の町で試す → 結果のデータをツインへ戻す
    → ツインはより現実に近づく（毎年くり返す）
```

## 🎮 ゲームの中身

| 要素 | 内容 |
|---|---|
| **役割** | 農家、漁師、物流会社、料理人、町長、医師・栄養士、商社、ひとつの家族……。国も時代も選べる |
| **ルール＝現実の法則** | 作物の育ち方、気温で変わる傷む速さ、輸送のCO2、栄養と病気の関係、値段の動きを、科学のモデルで再現 |
| **事件** | 干ばつ、エルニーニョ、戦争による港の封鎖、パンデミック、物価高騰 |
| **勝ち負けの基準** | 地球全体のスコア：飢える人ゼロ・健康寿命・CO2・廃棄量。ただし **「誰も前より悪くならない」（パレート改善）** が条件。誰かを犠牲にして勝つことはできない |
| **協力が中心** | 国や役割をまたいで協力しないと、地球のスコアは上がらない |

## 🌉 ゲームから現実への4つの橋

| 橋 | 内容 | 前例 |
|---|---|---|
| **① 知恵の橋** | ゲームで見つかった戦略を、オープンな提案として公開する | **Foldit**：プレイヤーが、科学者が長年解けなかったウイルスのタンパク質の構造を約10日で解いた（2011年） |
| **② 実証の橋** | よい戦略を、実際の町・農村で小さく試す | 地域の実証実験 |
| **③ データの橋** | 現実の結果をツインへ戻し、ゲームを現実に近づける | EUの地球デジタルツイン「Destination Earth」 |
| **④ 行動の橋** | ゲームのクエストが、現実の行動につながる | ポケモンGO、Coke ON ウォーク、そして **「狩りと実り」** |

### ④ 行動の橋：「狩りと実り」

人は太古から「探す・獲る・作る・分ける」ことが楽しいようにできています。その本能を、**現実の食べものを救う遊び** に変えます。

| 太古の本能 | 遊び | 現実で起きること | 報酬 |
|---|---|---|---|
| 採集 | 地図に「実り」が出現 | 閉店前の余りそうな食品を救う | その食品 |
| 大物狩り | 30人で「収穫レイド」 | 人手不足の農家の収穫を手伝う | 規格外の野菜 |
| 狩り | 珍しい獲物 | 獣害のジビエ・未利用魚を活かす | 肉・魚 |
| 道具づくり | クラフト | 家の余り物で料理する | レベルアップ・ポイント |
| 分ける | おすそ分けクエスト | 子ども食堂・困っている人へ届ける | 町の感謝・地域ポイント |

地球ツインで「この町は今、余りが多い」となると、現実のその町のプレイヤーにクエストが届きます。**ゲームの世界と現実の世界が、同じ信号で動きます。**

## 🧩 中心にある数学

地球全体の目標を一つの式にします。

```
最大化：Σ 健康 ＋ Σ 満足 − 食べものの廃棄 − 費用 − CO2
条件：  安全（アレルギー・食中毒）、栄養の基準、誰も前より悪くならない
        作る量 ＋ 在庫 ＝ 食べる量 ＋ 余り（すべての食材・地域・日で）
```

これを中央で解くのではなく、需給のずれを表す **影の価格** を配って、国・町・お店・農家・家庭がそれぞれ自分の最適を選ぶ形にします（双対分解）。
ゲームの報酬は、この影の価格そのものです。**ゲームが、地球全体の最適化を楽しく伝える画面になります。**

数学のくわしい説明は、姉妹プロジェクト [たべものすべてAI：統合最適化](https://github.com/birdnnjjhiroselittle/tabemono-subete-ai/blob/main/docs/integrated-optimization.md) にあります。

## 🛡️ 守ること

- **AIもゲームも、決めない**：示すのは選択肢と結果の予測だけ。決めるのは各国・各地域の人
- **誰のものにもしない**：オープンソース。運営は国際的な協同組合のような形にする
- **モデルの限界を正直に示す**：ゲームは現実の簡略版。現実で試す前に、必ず小さな実証を挟む
- **宣伝の道具にしない**：ルール・データ・モデルを公開し、誰でも検証できるようにする
- **データの主権**：各国・各地域・各家庭のデータは持ち主が管理する。共有するのは合計だけ
- **依存させない**：ガチャ・課金の誘導をしない。遊びすぎない設計にする

## 🪴 進め方

| 段階 | 内容 |
|---|---|
| 0 | 構想を公開し、仲間を集める（研究者・ゲーム開発者・農家・物流・医療・行政） |
| 1 | 小さなツイン：1つの町の食べものの流れを再現する簡単なゲーム ＋ 「狩りと実り」の実証 |
| 2 | 国のツイン：公開統計・天気・物流データで1つの国を再現。プレイヤーとAIで戦略を探す |
| 3 | 地球ツイン：FAOなどの公開データ・衛星データで世界を再現。国際的なプレイヤーコミュニティ |
| 4 | ゲームで見つかった戦略を、各地の実証で試し、結果をツインへ戻す循環を回す |
